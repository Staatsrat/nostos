# Security Policy

## Reporting Misuse

If you notice this project being used outside its intended purpose
(isolated lab environments, own systems, authorized research), please
report it to:

**mail@staatsrat.me**

Include a short description and, if public, a link or screenshot.
Please do not interact with the attacker or the misused infrastructure
yourself.

## Reporting Vulnerabilities

If you find a security issue in the code, report it privately to the
same address. Do not open a public issue.
