Some help to compile the pogramm:
---
Compile:
```
g++ main.cpp -o nostos -lcurl
```
Run:
```
./nostos
```
Together:
```
g++ main.cpp -o nostos -lcurl && ./nostos
```
To make a background process:
```
g++ main.cpp -o nostos -lcurl && ./nostos &
```
Killing it:
```
kill -9 <process id>
```
